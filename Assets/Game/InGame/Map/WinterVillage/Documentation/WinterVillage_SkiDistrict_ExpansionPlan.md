# Winter Village Ski District Expansion Plan

## 목표

현재 `WinterVillage_ConceptMap`의 큰 동선인 `시골 마을 → 베이스 롯지 → 중앙 슬로프 → 정상`을 유지하면서, 비어 있는 공간에 플레이 목적과 생활감을 부여한다. 완성형 외부 맵 프리팹을 배치하지 않고 기존 개별 소품과 프로젝트 전용 메시를 조합한다.

콘셉트 기준 이미지: `Assets/Game/InGame/Map/WinterVillage/ConceptArt/WinterVillage_SkiDistrict_ExpansionConcept_v1.png`

## 보유 에셋 적합성 평가

현재 프로젝트만으로 콘셉트의 약 80~85%를 같은 로우폴리 문법으로 재현할 수 있다. 완성형
`ski resort with env`와 `land ski resort`는 사용하지 않는다.

| 콘셉트 요소 | 판정 | 실제 사용 방식 |
|---|---|---|
| 펭귄 방문객 | 재사용 가능 | 게임의 `PF_PenguinProto`를 장식용 정적 인스턴스로 배치하고 플레이·물리 컴포넌트는 비활성화 |
| 베이스 대여소·패트롤·정상 산장 | 재사용 가능 | 프로젝트 소유 조명 포함 겨울집 프리팹 3종을 개별 배치 |
| 리프트·의자·코스 깃발 | 재사용 가능 | 벤더 팩의 개별 프롭만 사용하고 타워·케이블·기초는 프로젝트 메시로 구성 |
| 랜턴·표지판·썰매·삽·눈더미 | 재사용 가능 | 동선과 건물 사용 목적에 맞는 생활 군집으로 배치 |
| 정비 차량 | 부분 재사용 | 정적 픽업 차량에 프로젝트 소유 V형 제설 블레이드를 결합 |
| 초급자 매직카펫·콘·아치 | 직접 제작 필요 | 지형 추종 리본, 롤러, 난간, 콘 메시와 게이트를 생성 |
| 스노우파크 점프대·레일 | 직접 제작 필요 | 충돌 가능한 설면 웨지 메시 2개와 금속 레일 2개를 생성 |
| 전용 스노우캣·스노모빌 | 보유하지 않음 | 이번 정적 환경 범위에서는 제설 픽업으로 대체; 전용 모델 확보 전 가짜 복제는 하지 않음 |

첫 구현은 `ConceptMapSkiResortBuilder`가 위 구성을 결정적으로 재생성한다. 현재 펭귄과 정비
차량은 장소의 사용 흔적을 보여 주는 정적 연출이며, 실제 순환 이동·리프트 탑승·정설 자국은
별도의 NPC/이벤트 시스템 작업으로 남긴다.

## 현재 맵에서 유지할 것

- 중앙의 매끈한 주 슬로프와 우측 리프트
- 마을과 스키장을 연결하는 곡선 진입로
- 낮은 마을에서 높은 정상으로 이어지는 고도 방향
- 무광 로우폴리 재질, 푸른 설경, 따뜻한 창문과 랜턴 조명
- 에베레스트풍 외곽 산악 실루엣

## 제작 순서

### 1. 레이아웃 블록아웃

- 각 구역을 단순 박스와 컬러 디버그 메시로 표시한다.
- 주 슬로프 유효 폭과 리프트 안전거리를 침범하지 않는지 확인한다.
- 펭귄, 제설차, 스노모빌이 이동할 서비스 동선을 먼저 확보한다.
- 미니맵에서 다섯 구역이 서로 구분되는지 확인한다.

완료 기준: 게임 카메라와 탑다운 카메라 모두에서 구역의 역할이 형태만으로 읽힌다.

### 2. 지형과 눈 연결

- 베이스 광장과 건물 아래에는 평탄화된 눈 패드를 만든다.
- 초보자 연습장은 주 슬로프보다 완만한 별도 경사를 사용한다.
- 스노우파크 점프대는 지형과 일체형 메시로 제작하고 접합부를 눈더미로 가린다.
- 모든 구역의 바깥 경계에는 얇은 눈 둔덕과 바위·나무 군집을 배치한다.

완료 기준: 떠 있는 건물이나 구조물이 없고, 모든 바닥 경계가 설경으로 자연스럽게 이어진다.

### 3. 기능성 소품 제작

- 대여소, 매표소, 패트롤 오두막은 기존 건물 소품을 개별 조합한다.
- 매직 카펫, 점프대, 레일, 안전망, 장비 거치대는 프로젝트 전용 프리팹으로 만든다.
- 정상 산장은 작은 규모로 유지해 산 실루엣을 가리지 않는다.
- 재질은 Metallic 0, Smoothness 0.02~0.08 범위의 무광 카툰 스타일로 통일한다.

완료 기준: 반복 배치가 가능한 개별 프리팹 세트가 만들어지고 완성형 외부 맵 프리팹 의존성이 없다.

### 4. 생활감과 플레이 요소

- 펭귄 NPC 동선: 광장 대기, 리프트 탑승 대기, 초보자 연습, 정상 포토 포인트.
- 스노우캣은 주 슬로프를 천천히 왕복하며 정설 흔적을 남긴다.
- 패트롤 스노모빌은 폭설·충돌 이벤트 때만 출동한다.
- 발자국, 스키 자국, 눈가루 파티클은 플레이어 주변에서만 활성화한다.

완료 기준: 플레이어가 정지해 있어도 최소 세 종류의 반복 행동이 보인다.

### 5. 조명·사운드·날씨

- 베이스 광장과 정상 산장에는 따뜻한 주황색 조명을 집중한다.
- 슬로프와 리프트에는 낮은 조도의 길 안내 조명을 일정 간격으로 배치한다.
- 바람, 리프트 기계음, 멀리서 들리는 마을 소리를 구역별 Audio Zone으로 분리한다.
- 기본 강설과 블리자드 이벤트의 파티클 밀도 및 음량을 별도로 조절한다.

완료 기준: 광장·슬로프·정상이 빛과 소리만으로도 구분되고 카메라 노출이 과하지 않다.

### 6. 최적화와 QA

- 반복 나무·랜턴·펜스는 GPU Instancing을 사용한다.
- 멀리 있는 산, 건물, 리프트 의자에 LOD 또는 거리 비활성화를 적용한다.
- 경사면 충돌, 리프트 기초, 점프대 착지, 맵 경계를 플레이 모드에서 검사한다.
- 16:9 게임 카메라, 탑다운 미니맵, 야간·블리자드 상태로 각각 스크린샷 QA를 수행한다.

완료 기준: 신규 오류 없이 목표 프레임을 유지하고, 주요 오브젝트의 부유·관통·깜빡임이 없다.

## 우선순위

1. 베이스 리조트 광장과 구조·정비 구역
2. 초보자 연습장
3. 스노우파크
4. 정상 휴게 구역
5. NPC·차량·날씨 연출

정적 환경 1차 구현에서는 1~4순위를 모두 구축했다. 5순위 가운데 펭귄과 정비 차량의 정적 배치는
포함했고, 실제 NPC 이동·차량 이벤트·날씨 반응은 후속 런타임 작업으로 남겼다.
