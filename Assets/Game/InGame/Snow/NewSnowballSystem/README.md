# Snowball Growth Prototype

실제 게임 프리팹을 건드리지 않고 펭귄으로 직접 조작해 다음 항목을 확인하는 테스트 전용 프로토타입이다.

- 반지름 `0.18 m ~ 1.50 m`를 `0.33 m`씩 네 구간으로 균등 분할
- 물리 반지름의 이전·현재 틱 사이를 렌더 프레임마다 보간하는 표시 반지름
- 눈덩이 오른쪽 외곽을 따라가는 현재 단계 전용 곡선 HUD
- 단계 상승 시 0.35초 동안 최대 1.28배로 변형되는 Feel `MMF_SquashAndStretch` 팝

## 테스트 씬

`Tests/SnowballGrowthHud_Look_Test.unity`

- `WASD`: 펭귄 이동, 마우스: 카메라 회전
- `E`: 발밑 눈으로 눈덩이를 만들거나 전방 눈덩이를 선택
- 눈덩이 옆에서 `W`: 밀기, `A/D`: 밀기 방향 변경
- 기존 협동 우클릭 타이밍 미니게임은 이 격리 테스트 씬에서 비활성화된다.
- 씬의 펭귄에는 관성 실험 프로필과 300 kg 눈덩이 질량 바인더가 붙어 있어 3·4단계도
  `MomentumHandling` 씬과 같은 추진·조향 법칙으로 테스트한다.
- 실제 눈을 굴리면 각 단계 증가분의 40%까지 연속 성장하고, 승급 순간 남은 60%만큼 실제
  반지름·충돌체·질량이 함께 커진다.
- 곡선 HUD는 현재 선택한 눈덩이를 우선해 따라가며, 단계 상승 때 실제 크기 점프와 Feel 팝이
  함께 재생된다.
- `SnowballGrowthHud`의 `SnowballGrowthPlayableSceneController`에서 `Seed→1`, `1→2`, `2→3`, `3→4`
  기준 시간을 각각 조정할 수 있다. 기본값은 모두 7초다.
- 설정 시간은 타이머가 아니라 300 mm 처녀설을 해당 단계 진입 최고속도로 지날 때의 필요 수확량을
  계산하는 기준이다. 실제 진행은 필드에서 제거한 눈의 양을 누적하므로 얕은 길에서는 느려지고,
  이미 모두 파인 길에서는 멈추며, 남은 눈이 있으면 그 깊이만큼 연속적으로 반영된다.
- 표시·콜라이더와 설면 제거는 같은 반지름을 사용한다. 수확량은 단계 진행에 100% 반영되지만
  눈덩이 내부 취득 질량은 기존 0.5 성장 가중치를 유지하고, Rigidbody 질량에는 직접 더하지 않는다.
- Seed HUD는 이론적인 최소 반지름이 아니라 실제 생성 반지름을 0%로 기억해 시작한다.
- 4단계는 최대 반지름 `1.50 m`에서 진입한다. 곡선 게이지는 즉시 100%가 되고, 이후 압축
  질량이 늘어도 표시 반지름과 HUD는 그 상태로 고정된다. 설면은 계속 1.50 m 반지름으로 제거한다.
- 관성 실험에서 쓰는 조작용 질량은 균일 밀도 구체 법칙 `m = 300(r / 1.5)³`을 따른다.
  따라서 반지름 `0.18 m`에서는 `0.5184 kg`, `1.50 m`에서는 `300 kg`이다. 승급 순간에는
  실제 반지름이 커지는 만큼 이 법칙으로 계산한 질량도 함께 증가한다.
- 밀기 조작값은 Seed·1/2/3/4단계 진입의 다섯 기준점을 실제 반지름 진행도로
  연속 보간한다. 작은 공은 빠르게 반응하고, 큰 공은 낮은 목표 속도로 출발해 더 높은
  최고속도까지 오래 가속하며 고속 조향과 방향 전환 반응이 함께 낮아진다.
- 조향량 자체는 단계별 값이 아니라 실제 속도만 읽는다. 0 m/s의 1.00에서 9 m/s의 0.28까지
  감소하고, 9 m/s 이후에도 같은 기울기로 계속 내려가 12.5 m/s부터 0이 된다. 단계별로는
  방향 전환 후 조향권을 회복하는 시간만 달라진다.
- 숫자 `0`은 Seed, 숫자 `1~4`는 각 단계 진입 반지름으로 이동한다.

씬의 기반은 실제 통합 검증 씬 `Snow/Tests/Snow_BallPush_Test.unity`이지만, 추가 컴포넌트와
렌더 프록시는 이 테스트 씬의 런타임에만 만들어진다. 루트 스케일과 콜라이더는 물리 틱의 실제
반지름을 유지하고, 자식 렌더 프록시는 이전·현재 물리 반지름을 `LateUpdate`에서 보간한다.
따라서 60 FPS 화면과 50 Hz 물리의 갱신 차이가 크기 멈춤으로 보이지 않으며, 단계 상승의 실제
크기 점프는 한 물리 틱 안에서 따라간 뒤 짧은 Feel 팝으로 강조된다.

씬은 Build Settings에 추가하지 않는다. UI는 UI Toolkit `Painter2D`만 사용하며 런타임 래스터 확대는 없다.
