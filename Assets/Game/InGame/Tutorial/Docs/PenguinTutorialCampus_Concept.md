# Penguin Tutorial Campus

## 목표

기존의 좁은 직선 코스를 다섯 개의 넓은 훈련실로 분리한다. 각 방은 하나의 플레이어 행동만
가르치며, 낮은 벽과 7m 이상의 열린 출입구로 연결한다. 펭귄 카메라와 `SnowCpuStage`가
평면 높이맵을 사용하므로 모든 방은 같은 높이의 하나의 눈밭 위에 둔다.

![Campus concept](PenguinTutorialCampus_Concept.png)

## 공간 구성

1. **Walk Yard — Cyan**: 남서쪽 24×22m 방. 출발 지점과 넓은 발자국 루프를 둔다.
2. **Run Lane — Green**: 남쪽 중앙 24×18m 방. 장애물이 없는 18m 직선 주로를 둔다.
3. **Slide Chute — Orange**: 남동쪽에서 북쪽으로 이어지는 24×30m 방. 넓은 회전 구간과 바닥 화살표를 둔다.
4. **Snowball Basin — Cyan**: 북동쪽 26×24m 방. 눈덩이를 여러 방향으로 밀 수 있는 원형 연습 공간을 둔다.
5. **Gift Dock — Green**: 북서쪽 26×24m 방. 선물 스폰 패드와 따뜻한 조명을 둔다.

가운데는 비워 두어 방 사이의 시야와 카메라 회전 공간을 확보한다. 다음 단계의 색상 게이트가
현재 방에서 보이도록 U자형 시계 방향 동선으로 연결한다.

## 구현 기준

- 전체 눈 영역을 약 96×72m로 확장한다.
- 외곽과 방 구분 벽은 높이 1.0~1.2m로 제한하고 충돌체를 유지한다.
- 체크포인트 폭은 7m 이상 유지하고, 머리 위 프레임 대신 약 1.6m 높이의 눈 덮인 방향 기둥을 양쪽에 둔다.
- 장식은 기존 튜토리얼의 navy/cyan/green/orange 머티리얼과 Unity primitive를 재사용한다.
- 진행 판정은 기존 실제 `PenguinLocomotion`, `PenguinSnowball`, `PenguinCarry` 상태를 그대로 사용한다.
- 이동 입력을 잠그거나 플레이어를 강제로 순간 이동시키지 않는다.

## 검증

- 씬 구조 검증에서 플레이어, 눈 시스템, 선물, 마커, UI가 각각 하나씩 연결되어야 한다.
- Play Mode에서 Walk 단계가 시작되고 런타임 예외가 없어야 한다.
- 플레이 캡처에서 벽이 펭귄과 다음 목표를 가리지 않고 조작표가 잘리지 않아야 한다.
