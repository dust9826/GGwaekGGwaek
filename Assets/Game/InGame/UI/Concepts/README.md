# Vacuum Mode Dial Concept

`VacuumModeSwitchInGameTargetIconsConcept.png`가 현재 전체 화면 컨셉이다. 청소기 도구를 반복해서 보여주지 않고 청소 대상 자체를 아이콘화해, 먼지 모드는 먼지 덩어리와 입자, 프롭 모드는 테이프가 붙은 작은 상자로 표현한다. `VacuumModeSwitchInGameSimpleConcept.png` 이전은 도구 프롭 기반 탐색안으로 보관한다. 이미지들은 런타임 텍스처가 아니며 실제 UI Toolkit 구현 시 구조와 움직임을 참고한다.

## 핵심 컨셉

- 전체 UI는 화면 오른쪽 하단 약 10~12% 이내로 제한한다.
- 전체 화면 합성 기준으로 컴포넌트 폭은 화면의 약 15~17%, 높이는 약 20~24%이며 오른쪽·아래쪽에 28~36px의 안전 여백을 둔다.
- 현재 모드와 다음 모드는 원형 프레임 없이 청소 대상을 나타내는 스티커 아이콘 두 개로 표시한다.
- 먼지 모드는 회갈색 먼지 덩어리와 3~5개의 작은 입자, 프롭 모드는 노랑 상자와 코랄 테이프로 구분한다.
- 각 아이콘은 3~4개의 큰 색면, 굵은 흰 테두리와 작은 남색 오프셋 실루엣만 사용한다.
- 흰 상면과 얇은 남색 측면을 가진 짧은 2.5D 타원 궤도 화살표가 회전 방향을 설명한다.
- 화살표의 뒤쪽 구간은 후방 프롭 뒤에 가리고, 앞쪽 화살촉은 두 프롭 앞으로 나오게 해 실제 궤도 깊이를 만든다.
- `R` 입력 시 두 프롭이 짧게 교차하며 앞뒤 위치와 크기를 바꾼다.
- 원형 토큰, 링, 다이얼, 모드명 패널, 상세 웨지와 펼쳐지는 메뉴는 사용하지 않는다.
- 시작 화면에서 사용한 민트, 파랑, 초록, 코랄, 노랑과 굵은 흰색 테두리를 유지한다.
- `SUCTION`, `BRUSH`, `BLOW`는 탐색용 임시 모드 이름이며 게임 기획 결정으로 간주하지 않는다.

## 구현 힌트

- 먼지와 프롭 아이콘을 UI Toolkit 도형 또는 투명 Sprite로 만들고, 각각 남색 실루엣을 한 겹만 둔다.
- Feel은 화살표 스윕, 키캡 눌림, 프롭 착지 펀치를 담당하고 DOTween은 두 프롭의 위치·크기·정렬 순서 교체를 담당한다.
- 앞 프롭은 `1.0 → 0.78`, 뒤 프롭은 `0.78 → 1.08 → 1.0`으로 바꾸며 전체 전환은 약 `0.28~0.34초`에 끝낸다.
- 화살표를 후경 궤도와 전경 화살촉 레이어로 나누고, `overflow: visible`인 공통 회전 컨테이너 안에 둔다.
- Feel은 궤도를 `0 → 18° → 0°`로 짧게 흔들고 화살촉에 착지 펀치를 주며, DOTween은 두 프롭의 실제 자리 교체를 수행한다.
- 최종 구현 전 게임에서 실제 사용할 모드 수와 입력 방식부터 확정한다.

## 생성 프롬프트 요약

기존 청소 게임 화면의 월드·전경 청소기는 유지하고 모든 기존 HUD는 제거, 오른쪽 하단에만 회갈색 먼지 덩어리 아이콘과 노랑·코랄 프롭 상자 아이콘, 짧고 얇은 2.5D 타원 궤도 화살표, 작은 `R` 키캡을 배치.

## Trash Prop Outline Only Concept

`TrashPropOutlineOnlyConcept.png`은 물리 쓰레기 프롭을 먼지 표면과 구분하는 최소 표현안이다.

- 카드, 이름표, 스캔 안내, 조준 괄호, 바닥 링과 모드 HUD는 사용하지 않는다.
- 각 프롭의 실제 화면 실루엣에 코랄 오렌지 `#F15B42` 테두리만 밀착시킨다.
- 테두리는 오브젝트를 가리지 않는 균일한 굵기로 유지하고 흰 외곽, 글로우, 그림자와 내부 색 틴트는 추가하지 않는다.
- 이미지는 런타임 텍스처가 아닌 검수용 콘셉트다. 실제 효과는 프롭 렌더러의 선택적 아웃라인으로 구현한다.

생성 방식: Codex built-in ImageGen으로 `TrashPropShowcaseFinal.png`을 편집했으며, 원본 월드와 프롭은 유지하고 기존 HUD 오버레이만 제거했다.
