# Tropical Co-op HUD Concept

`TropicalCoopHUDConcept.png`은 야외 3인 협동 청소 화면을 위한 InGame HUD 기준안이다.

## 구성

- 상단 중앙: 공용 청소 진행률과 물방울 상태 배지
- 왼쪽: P1/P2/P3 초상화와 얇은 상태 아크를 결합한 소형 스티커 칩
- 월드 표식: 크림 외곽선의 민트·파랑 하향 셰브론
- 왼쪽 하단: 로컬 플레이어용 짧은 분절 상태 미터
- 오른쪽 하단: 먼지/프롭 도구, 정적인 단일 반투명 타원, `R` 키캡
- 오른쪽 하단 보조 입력: 크림 스티커 안의 청록 분사 아이콘

## 적용 원칙

- 월드와 캐릭터 가시성을 우선하며 화면 중앙에는 HUD를 배치하지 않는다.
- 크림색 3~4px 외곽선, 남색 오프셋 그림자, 청록·파랑 주조색을 공통으로 사용한다.
- 타원은 도구의 관계만 설명하는 정적 가이드이며 이동·회전·펄스를 적용하지 않는다.
- 모바일식 대형 원형 버튼, 과도한 네온 글로우, 유리 재질 패널은 사용하지 않는다.
- 실제 구현은 `../AGENTS.md`와 `../VacuumModeSwitch/README.md`의 데이터·모션 규칙을 따른다.

## 생성 정보

- 생성 방식: Codex built-in ImageGen edit
- 편집 대상: 사용자가 제공한 열대 광장 협동 청소 화면
- 스타일 참조: 현재 `VacuumModeSwitch` 프리뷰와 기존 InGame UI 시안
