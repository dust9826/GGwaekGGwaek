# Blizzard Event Test Scene

Open `BlizzardEvent_Test.unity` and enter Play Mode.

- The event starts automatically and uses a shortened cycle for inspection.
- `TRIGGER` / `Space`: start the event if it is idle or cooling down.
- `RESTART` / `R`: restart from the warning phase.
- `STOP` / `S`: stop and restore presentation intensity.
- The top-left panel shows the current phase, intensity, phase progress, and authoritative `SnowStage` depth at the event center.
- The scene starts with a cleared snow grid so positive event accumulation is visible in the depth value.
- The vehicle remains drivable to inspect snowfall, wind, fog, and snow interaction from the gameplay camera.
