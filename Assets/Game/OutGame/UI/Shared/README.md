# Shared OutGame UI

`SnowRemovalTheme.uss`는 `MainMenu` 단일 씬의 공통 산타 마을 제설 표현을 담당합니다.

- 밤하늘 남색 배경, 눈색 카드, 산타 레드/솔잎 초록 행동 버튼과 랜턴 골드 선택 강조를 사용합니다.
- 아래쪽 눈 둔덕, 수평 바람선, 작은 눈 결정과 먼 등불은 UXML/USS 도형입니다.
- 배경에 걸레·청소기·물방울 같은 청소 도구 그림이나 외부 래스터 스프라이트를 사용하지 않습니다.
- `OutGameTransitionWipe`는 씬을 로드하지 않고 현재 `menu-view`를 다음 패널로 교체합니다. 전환은 위치 이동, 좌→우 밀기, 눈보라 와이프 없이 짧은 페이드만 사용합니다.
- 호버 눈 결정만 `ui-effect-layer`에 런타임 UI Toolkit 도형으로 생성합니다. 클릭과 패널 도착에는 버스트를 사용하지 않으며, 결정은 입력을 가로채지 않고 Tween 완료 시 계층에서 제거됩니다.
- 배경 `winter-twinkle` 요소는 서로 다른 주기로 크기와 투명도를 반복해 정적인 겨울 화면에 낮은 강도의 생동감을 줍니다.
- 공용 `StartScreenPanelSettings`는 `1600 x 900` 기준 `Scale With Screen Size`를 사용합니다. Retina와 더 큰 해상도에서는 UI Toolkit 도형과 TTF 글꼴을 해당 출력 해상도로 다시 그려 선명도를 유지합니다.
- Player 창 모드 기본 해상도는 `1600 x 900`이며 창 크기 변경 시 렌더 해상도도 함께 갱신합니다.
- `Preview` PNG는 런타임 에셋이 아니므로 원본 픽셀 크기보다 확대하면 흐려질 수 있습니다. 확대 검수에는 별도의 4K 캡처를 사용합니다.
- 실제 게임 씬 전환은 메뉴 패널 페이드와 분리된 `LoadingScreen`에서 제설차가 눈더미를 밀어 도로를 여는 연출로 전달합니다.
- Unity Material은 사용하지 않습니다.
