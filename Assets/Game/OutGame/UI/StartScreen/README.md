# Start Screen Archive

기존 시작 화면의 UXML/USS와 프리뷰를 디자인 참고용으로 보관합니다. 런타임 `StartScreen` 씬과 컨트롤러는 제거됐으며 게임은 `MainMenu` 씬에서 바로 시작합니다.

- 현재 런타임 기준: `../MainMenu/MainMenu.uxml`
- 현재 첫 씬: `../MainMenu/Scenes/MainMenu.unity`
- `Audio/`의 Kenney UI 호버 사운드는 MainMenu 씬이 계속 참조합니다.
- `StartScreenPreview.png`는 이전 시각 방향을 확인하기 위한 기록이며 런타임 에셋이 아닙니다.
