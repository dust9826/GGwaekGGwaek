# 1. 게임 개요

- **장르:** 3인칭 멀티플레이 협동 액션 / 스테이지 클리어
- **핵심 비유:** 쥬시한 청소 액션 + 가볍고 유쾌한 협동 플레이
- **목표:** 쓰레기·먼지 프롭과 벌레 몬스터를 제거해 일상 공간을 깨끗하게 만들고 목표를 달성
- **분위기:** 밝고 경쾌한 일상 테마
- **레퍼런스:** 폴가이즈, 슈퍼 마리오 오디세이
    
    # 2. 핵심 재미
    
1. **도구별 청소 손맛:** 청소기의 강한 흡입감과 대걸레의 밀기·당기기·내리치기가 서로 다른 리듬과 타격감을 만든다.
2. **쥬시한 도구 액션:** 대상의 변형, 궤적, 진동, 사운드, 파티클을 겹쳐 모든 청소 행동에 즉각적이고 과장된 반응을 제공한다.
3. **청소의 시각적 만족:** 더러운 공간이 깨끗해지며 전후 차이가 선명하게 보이는 변화.
4. **협동 리듬:** 도구와 역할을 나누거나 한 목표에 힘을 집중하는 팀 플레이.

## 디자인 원칙

- 입력은 단순하되 반응은 풍부해야 한다.
- 항상 “내가 공간을 바꾸고 있다”는 흔적이 보여야 한다.
- 협동 행동의 필요성과 결과가 설명 없이도 명확하게 보여야 한다.

# 3. 코어 루프

**스테이지 진입 → 쓰레기·오염·벌레 탐색 → 청소기와 대걸레 선택·활용 → 도구별 청소 및 협동 액션 → 플레이어들이 청소 완료 여부 판단 → 종료 버튼 활성화 → 실제 청소 완료 여부 판정 → 성공 또는 실패 → 팀 성과 확인 → 다음 스테이지**

> **싱글플레이는 이 루프를 따르지 않는다(2026-08-25).** 종료 버튼과 5분 스테이지 제한이 없고,
> 플레이어 선물 주문을 성공하는 동안 계속된다. 주문 하나의 제한시간이 끝나면 자동 종료하고
> 플레이 시간, 완료 배송 수, 제설률을 기록으로 보여 준다. 구현 결정은 `InGame/Cleanliness/AGENTS.md`.
> **멀티플레이가 아래 흐름을 그대로 유지할지는 미정이다** — §9 참고.

## 스테이지 종료 흐름 (멀티플레이)

- 각 스테이지는 **시간 제한 없이** 진행된다.
- 게임이 자동으로 종료되지 않으며, 플레이어들이 청소가 충분히 끝났다고 판단한 뒤 종료 버튼을 눌러 판정을 요청한다.
- 종료 버튼이 활성화되면 남은 쓰레기, 오염, 벌레와 필수 청소 목표를 기준으로 실제 완료 여부를 확인한다.
- 모든 필수 청소 조건을 충족했다면 스테이지 성공, 하나라도 남아 있다면 스테이지 실패로 처리한다.
- 종료 판정 전에는 숨은 오염이나 남은 목표를 직접 찾아야 하며, 플레이어의 관찰과 팀 의사결정이 스테이지의 마지막 과정이 된다.

# 4. 청소 도구 조작과 카메라

## 청소기

- **좌클릭을 누르는 동안** 전방의 대상을 빨아들이고, 버튼을 떼면 즉시 흡입을 멈춘다.
- 청소기의 방향은 수평으로만 움직이며 **Y축 조준은 지원하지 않는다.**
- 대상은 수평 흡입 범위, 각도, 시야 및 장애물 판정의 영향을 받는다.
- 흡입 중에는 대상이 늘어나고 흔들리다가 나선형 궤적으로 빨려 들어오며, 저음 흡입음·파티클·진동으로 강한 손맛을 만든다.

## 대걸레

- **좌클릭 짧은 입력 또는 드래그:** 대걸레를 앞으로 밀어 바닥의 오염과 대상을 쓸어낸다.
- **우클릭:** 대걸레를 몸 쪽으로 당겨 오염과 대상을 끌어온다.
- **좌클릭 홀드:** 대걸레를 들어 올리며 차징한다. 버튼을 놓으면 바닥으로 빠르게 내리쳐 범위 안의 벌레를 잡는다.
- 밀기와 당기기는 바닥 자국, 물기 궤적, 마찰음, 대상의 밀림과 찌그러짐으로 방향성과 힘을 명확하게 보여준다.
- 차징 중에는 자세·대걸레 높이·사운드·발광으로 힘이 축적되는 과정을 표현하고, 내리칠 때 히트 스톱·화면 흔들림·충격파·강한 진동을 겹쳐 핵심 쥬시 모먼트로 연출한다.

## 상태별 카메라

- **도구 작동 중:** 화면 회전에 맞춰 플레이어도 회전한다. 도구의 작동 방향을 명확히 고정해 즉각적인 조작감을 준다.
- **정지 중:** 플레이어 방향은 유지되고 화면만 자유 회전한다. 이동을 방해하지 않고 주변을 관찰한다.

## 입력 판정 원칙

- 대걸레 좌클릭은 짧은 입력·드래그와 홀드 차징의 경계가 즉시 이해되어야 한다.
- 차징으로 전환되기 전까지는 밀기 동작의 반응이 지연되었다고 느껴지지 않도록 한다.
- 차징을 취소할 수 있는지와 차징 단계별 위력·범위 변화는 프로토타입에서 검증한다.

## 프로토타입 검증

- 청소기의 수평 흡입 범위와 자동 보정 강도.
- 도구 작동 중 이동 속도 및 선회 속도 감소 여부.
- 화면과 플레이어가 함께 돌 때 멀미 가능성.
- 여러 명이 같은 대상을 흡입할 때 합산, 분배, 줄다리기 중 어떤 반응이 재미있는지.
- 대걸레 밀기·당기기의 이동 거리, 판정 범위, 반복 속도.
- 좌클릭 밀기와 홀드 차징이 오입력 없이 자연스럽게 구분되는지.
- 내리치기의 차징 시간, 공격 범위, 벌레 처치 기준.

## 협동 과부하 파쇄

- 대형 몬스터나 큰 오브젝트에 여러 플레이어가 동시에 흡입을 집중하면 **협동 과부하 게이지**가 상승한다.
- 임계치에 도달하면 대상이 버티다가 팽창·진동한 뒤 시원하게 터지며 여러 개의 작은 조각 또는 소형 개체로 분리된다.
- 분리된 조각들은 폭발 중심에서 바깥으로 포물선을 그리며 날아가고, 잠깐 튕긴 뒤 다시 흡입 가능한 상태가 된다.
- 플레이어들은 흩어진 작은 조각을 빠르게 회수하며 **집중 협동 → 폭발 → 분산 회수**의 리듬을 경험한다.
- 참가자가 많을수록 게이지 충전 속도는 빨라지되, 대상별 최소 협동 인원과 최대 효율 상한을 둔다.
- 파쇄 순간에는 화면 흔들림, 히트 스톱, 저음 충격음, 파편별 팝 사운드, 강한 진동을 겹쳐 핵심 쥬시 모먼트로 연출한다.
- 생성된 파편의 수집 점수는 마지막 타격자가 독점하지 않도록 기여도 분배 또는 팀 보너스로 처리한다.
- 소형 몬스터로 분리되는 경우 짧은 경직 후 다시 움직이게 하여, 폭발 직후 팀이 빠르게 마무리하도록 유도한다.

# 5. 콘텐츠 분류

- **쓰레기:** 연속 흡입되는 소형, 저항하는 중형, 협동이 필요한 대형.
- **매립형 협동 인양 프롭:** 땅에 깊이 박혀 있어 한 명의 청소기로는 꺼낼 수 없는 대형 쓰레기. 정해진 최소 인원이 동시에 흡입해야 인양 게이지가 차오르고, 힘이 부족하면 프롭이 흔들리기만 하거나 서서히 원위치로 돌아간다.
    - 여러 흡입 궤적이 한 점에 모이고 땅이 갈라지며 프롭이 단계적으로 들리는 연출로 협동 상태를 즉시 보여준다.
    - 참가 인원에 따라 청소기 소리와 진동이 겹쳐지고, 마지막 순간에는 코르크 마개처럼 크게 튀어나오는 강한 팝 연출을 준다.
    - 성공 시 일반 프롭보다 많은 쓰레기 자원 또는 팀 보너스를 제공한다.
    - 보상은 팀 자원으로 지급하고, 필요하면 각 참가자의 **협동 기여도**를 별도로 기록한다.
    - 배치 시 모든 플레이어가 접근할 수 있는 공간과 집결 시간을 보장하며, 필수 진행 프롭이라면 인원 이탈 시 요구 인원을 동적으로 보정한다.
- **먼지·바닥 오염:** 넓게 퍼져 청소 전후 대비를 크게 보여준다. 청소기로 흡입하거나 대걸레의 밀기·당기기로 닦아낼 수 있으며, 오염 종류에 따라 적합한 도구를 구분할 수 있다.
- **벌레:** 도주형, 돌진형, 쓰레기 생성형, 청소 도구 방해형, 대형 엘리트. 일반 벌레는 대걸레 차징 내리치기로 잡을 수 있고, 대형 개체는 여러 명의 협동 흡입으로 파쇄되어 여러 소형 개체로 분리될 수 있다.
- **파쇄 가능 대형 오브젝트:** 여러 명이 동시에 흡입하면 내구 또는 과부하 임계치에 도달해 작은 흡입 프롭들로 폭발·분해된다.
- **환경:** 움직이는 카트, 미끄러운 바닥, 선풍기 바람, 가구를 활용한 수직 공간, 흡입 가능한 생활 장애물.
- **보너스:** 숨겨진 쓰레기 더미, 청소 효율 보조 오브젝트, 협동 보너스 구간.

# 6. 아트·오디오

- 친숙한 일상 공간을 밝고 경쾌한 색감과 과장된 비율로 재해석한다.
- 둥글고 읽기 쉬운 실루엣, 밝은 고채도 색상, 장난감 같은 재질을 사용한다.
- 오염과 청소 완료 상태의 색·광택·파티클 대비를 크게 한다.
- 벌레는 불쾌하기보다 우스꽝스럽고 귀여운 방해꾼으로 표현한다.
- 사운드는 청소기의 저음 흡입감, 대걸레의 마찰음과 묵직한 충돌음, 대상별 팝, 협동 성공 순간의 풍부한 레이어로 구성한다.

# 7. 성공·실패와 보상 (멀티플레이 — 싱글플레이는 §3 상단 참고)

- **시간 제한:** 없음. 플레이어들은 원하는 만큼 스테이지를 탐색하고 청소할 수 있다.
- **종료 요청:** 플레이어들이 청소 완료를 판단한 뒤 종료 버튼을 눌러 최종 판정을 시작한다.
- **성공:** 종료 판정 시 모든 필수 쓰레기·오염·벌레 및 스테이지 청소 조건이 완료된 상태.
- **실패:** 종료 판정 시 필수 청소 대상이나 조건이 하나라도 완료되지 않은 상태. 성급한 종료 판단 자체가 실패 원인이 된다.
- **개인 지표:** 수집량, 벌레 제거, 지원 행동.
- **팀 지표:** 총 청소도, 완료 시간, 합동 처리, 팀원 구조, 종료 판정 정확도.
- **보상 후보:** 외형, 청소기·대걸레 파츠, 감정 표현, 칭호, 신규 스테이지와 환경 변형.

# 8. MVP 권장 범위

- 2–4인 온라인 협동.
- 일상 테마의 기본 청소 스테이지 1개.
- 소형·중형·대형 쓰레기 각 1종, 먼지 1종, 벌레 2종.
- 청소기 좌클릭 홀드 흡입과 수평 조준.
- 대걸레 좌클릭 밀기, 우클릭 당기기, 좌클릭 홀드 차징 및 내리치기.
- 도구 작동·정지 상태에 따른 카메라 전환.
- 시간 제한 없는 스테이지 진행과 플레이어용 종료 버튼.
- 종료 버튼 입력 시 남은 필수 청소 대상을 검사하는 성공·실패 판정.
- 청소도, 개인 기여도, 팀 성과 UI와 결과 화면.

# 10. 첫 플레이테스트 질문

1. 청소기 흡입이 좌클릭 직후부터 시원하고 강하게 느껴지는가?
2. Y축 조준 없이도 청소기의 수평 흡입 범위와 대상을 명확히 예측할 수 있는가?
3. 대걸레의 밀기와 당기기가 서로 다른 방향과 힘으로 즉시 구분되는가?
4. 좌클릭 밀기와 홀드 차징 내리치기가 오입력 없이 자연스럽게 구분되는가?
5. 대걸레 차징 과정과 내리치기가 충분히 쥬시하고 벌레를 잡는 보상감이 있는가?
6. 청소기와 대걸레가 각각 필요한 상황과 역할을 설명 없이 이해할 수 있는가?
7. 팀원과 함께 청소한다는 감각이 실제 행동으로 나타나는가?

9. 동시에 힘을 합쳐 프롭을 뽑는 순간이 충분히 쥬시하고 보상감 있게 느껴지는가?

12. 파쇄 후 흩어진 조각을 회수하는 과정이 번거롭지 않고 청소 흐름의 즐거운 연장으로 느껴지는가?
13. 시간 제한이 없어도 플레이어들이 지루해하지 않고 스스로 청소를 마무리할 수 있는가?
14. 종료 버튼을 누르는 시점에 팀원 간 자연스러운 확인과 합의가 이루어지는가?
15. 청소 미완료로 실패했을 때 남아 있던 대상을 이해하고 결과를 납득할 수 있는가?
