# 용어 기준

기획서(한국어)와 코드 식별자(영어)를 잇는 사전. **새 용어나 코드 식별자는 도입 전에 여기 먼저 등록한다.** 문서·코드·대화가 어긋나면 이 파일을 기준으로 정리하고, 결정이 바뀐 것이라면 이 파일을 갱신한다.

KimOhOh는 이 단계가 없어서 개인 이름이 네임스페이스(`KimOhOh.Kim`)로 굳었고 229개 파일에 남았다.

## 용어

| 스테이지 | `Stage` | 한 판. **시간 제한 없음.** MVP는 1개 |

| 매립형 협동 인양 프롭 | *미정* | 땅에 박혀 최소 인원이 동시에 흡입해야 뽑히는 대형 쓰레기 |
| 먼지·바닥 오염 | `Dust` | 바닥 오염 전부. 넓은 먼지와 경계 뚜렷한 얼룩이 **같은 시스템** |

| 질량 불변량 | `invariant=` | `field + carried + deleted − initial`. 허용오차는 **비례**(`max(3 L, 2 ppm)`) — 절대값은 1 ppm 에 LEAK 을 외쳐 진짜 누출을 가린다. **단조 드리프트가 누출이고 0 근처 진동은 float32 노이즈다** |
| 미배치량 | `unplaced=` | 놓으려 했으나 못 놓은 부피(리터). **영원히 0 이어야 한다** — 경계 정규화를 잊은 emit 경로를 즉시 드러내는 감시자 |
| 블레이드 동사 | `EBladeAngle` 등 | 셋뿐이다: 내림/올림(제설/이동) · 좌/정면/우(던지는 방향) · 전진/후진(쌓기/놓기). **덤프 버튼이 없다** — 후진이 하역이고, 블레이드를 올리는 것도 같은 기구다 |
| 구운 로브 | baked lobe | 구 격자를 **높이 기여**로 바꿔 텍스처에 구운 것. 픽셀당 재평가하면 +9.31 ms, 구우면 +1.70 ms. 높이함수를 유지하므로 상한이 정확히 `+r` 이다 |
| 눈덩이 | snowball | 굴리면 커지는 눈덩이. 권위는 `SnowBallCpu`(순수 C#), 씬 오브젝트는 `SnowBallCarrier`, 프리팹은 `Snow/Resources/PF_SnowBall` |
| 공이 든 눈 | `BallHeldMm` | 공들이 들고 있는 눈의 합(mm·셀). 보존 불변량의 두 번째 항 — `필드 + 공 + 설명된 손실 = 초기` |
| 잔량 | `residueMm` | 공이 지나간 셀에 남기는 눈(mm). 실제 필드 수확량을 정하며, 표시 상한 1.5 m 이후에도 초과 압축 질량의 증가 속도에 계속 영향을 준다 |
| 타일 | tile | 지면 눈 패널을 쪼갠 **렌더 단위**. 머티리얼·텍스처·UV 공간은 한 벌을 공유하고 메시만 나뉜다 — 그래서 셰이더가 안 바뀌고 이음매가 안 생긴다. 권위 격자와 무관하다(`SnowPanelTiling`, `SnowDisplaceView.Tile Size M`) |
| 정점 격자 | vertex lattice | 패널을 덮는 전역 정점 배열. 타일은 그 **인덱스 구간**만 가져간다 — 좌표를 타일 로컬로 다시 계산하면 부동소수가 갈려 공유 모서리에 실금이 간다 |
| 렌더 더러움 | `RenderDirtyChunks` | 렌더가 아직 안 가져간 청크. 네트워크가 쓰는 `ChangedChunks` 와 달리 **`BeginStep` 이 안 비운다** — 한 프레임에 `FixedUpdate` 가 0~N번이라 스텝마다 비우면 렌더가 마지막 것만 본다 |
| 구역(눈) | region | 각자 원점·바닥면을 가진 **독립 필드**. 월드 XZ 격자를 타일로 쪼갠 것이 아니다 — 그 정의여야 지붕·램프가 XZ 로 겹칠 수 있다. 지금의 구현체가 `SnowZone` 이다 |
| 증강 | `Augment` | 하루가 넘어갈 때 3장 중 1장을 골라 얻는 강화. **판 단위 팀 공유**이지 플레이어별이 아니다 — 의뢰에 완료자 개념이 없어서 개인 귀속이 계산되지 않는다. 좋은 것에는 패널티가 붙는다 |
| 로드아웃 | `AugmentLoadout` | 이 판이 얻은 증강 전부. 스탯별 합산값을 소비처에 준다. **static 이 아니다** — 소유 결정이 뒤집혀도 붙이는 위치만 바뀐다 |
| 증강 추첨 | `AugmentDraft` | 풀에서 가중치로 3장 뽑는 순수 함수. 보유분은 제외하고, 모자라면 있는 만큼만 준다 |
| 투표 유예 | `_voteGraceSeconds` | 전원이 표를 낸 뒤 남기는 3초. **그동안 표를 바꿀 수 있다.** 단독 플레이에는 두지 않는다 — 방금 자기가 누른 것을 기다릴 이유가 없다 |
| 결과 공개 | `_revealSeconds` / `RevealRemainingSeconds` | 이긴 카드를 보여주는 1.5초. 새 복제 상태가 없다 — **열려 있는데 승자가 정해진 것**이 곧 이 단계다 |
| 투표 표시 묶음 | `AugmentVoteDisplay` | 투표 화면이 이 프레임에 그릴 값 전부. 허브→디렉터→뷰 세 겹을 그대로 지나간다. 판정하지 않는다 |
| 증강 스탯 | `EAugmentStat` | 효과가 꽂히는 축. **값은 언제나 가산 누적**이고, 배율로 쓰는 쪽이 `1 + 값` 으로 읽는다. 확률 스탯은 그대로 읽는다 |


## 아직 이름이 없는 것

- **협동 운반** — 여러 명이 대형 물체를 함께 옮기는 동작. 예상 플레이 화면에만 나오고 기획서에는 없다. 매립형 인양(뽑아내기)과는 다른 메커니즘이다
- **야간 변형** — 어두운 조명과 손전등. 예상 플레이 화면에만 나온다
- 기획서 9장의 미정 사항 10건 — 플레이어 수, 중도 참가 정책, 종료 버튼 활성화 방식(전원 동의/과반/방장) 등
